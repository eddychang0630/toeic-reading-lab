# ReadLab｜多益閱讀練習室

手機優先的多益閱讀自學 App，適合目前約 600–750、希望向 850+ 前進的學習者，也可在平板與電腦使用。

**線上使用：[ReadLab](https://eddychang0630.github.io/toeic-reading-lab/)**

## 內容與功能

- 15 章完整文法講義，保留原教材並修正過度簡化的規則、部分譯文及歧義選項。
- 133 題含中文解析：Part 5 93 題、Part 6 16 題、Part 7 24 題。
- 10 個閱讀題組，涵蓋單篇、雙篇、三篇商務情境，練習細節、同義改寫、推論與跨文件整合。
- 每日混合練習優先未作答與弱點，完整保留閱讀題組；首次 10 題含 Part 5／6／7。
- Part 5 限時 30 題／12 分鐘，閱讀題組亦可限時；交卷後才顯示答案。
- 錯題重做與 1、3、7、14、30 天複習間隔，首次作答統計不會被重做覆蓋。
- 48 組商務詞彙卡、28 天學習計畫、收藏、字級調整與深色模式。
- 首次連線完整載入後可離線使用，可加入手機主畫面。
- 本機儲存進度，提供 JSON 匯出／匯入移轉與備份。裝置間不會自動同步。

## 建議每日使用

1. 用 5 分鐘複習到期錯題，先說出判斷線索再作答。
2. 完成每日混合練習，閱讀題目時為每個答案找原文證據。
3. 花 10 分鐘檢討：為何正確、其他選項錯在哪裡、原文如何同義改寫。
4. 看學習進度，挑一個薄弱文法單元或商務詞彙補強。每週完成幾組限時閱讀。

## 存成手機 App

- iPhone／iPad：用 Safari 開啟網址 → 分享 → 加入主畫面。
- Android：Chrome 選單 → 安裝應用程式／加入主畫面。
- 完成第一次載入後，在設定頁確認「離線教材已備妥」。
- 更換瀏覽器、清除網站資料或使用私人瀏覽前，請先在「設定與備份」匯出紀錄。

## 本機開發

不需安裝前端依賴或執行建置。使用 Node.js 20 以上：

```text
node scripts/serve.mjs
node --test
node scripts/validate.mjs
```

預覽：http://127.0.0.1:4173 。GitHub Pages 以 main 分支根目錄發布，所有資源均使用相對路徑。

`scripts/extract-handbook.py` 可重建 `data/handbook.mjs`；只使用 Python 標準函式庫。原始 `多益閱讀文法自學講義.html` 保持原樣。內容稽核與修訂細節見 [docs/content-audit.md](docs/content-audit.md)。

## 驗證

Node 測試覆蓋紀錄匯入驗證、首次統計、錯題排程、當地日期與連續天數、完整題組選取及限時邊界。資料驗證檢查題目唯一性、四選一答案、文章關聯、學習計畫與離線資源。

網站另外以瀏覽器驗證手機、平板、電腦的閱讀版面、作答解析、收藏、交卷、錯題重做、重開保存、字級與詞彙卡。

## 教材與來源

題目為自學練習，非官方試題；顯示練習正確率與速度，不能直接換算正式 TOEIC 分數。28 天計畫與時間配置為練習建議，不保證成績。

測驗格式依 [ETS 考生手冊](https://www.ets.org/pdfs/toeic/toeic-listening-reading-test-examinee-handbook.pdf)：閱讀 100 題、75 分鐘，Part 5／6／7 分別為 30／16／54 題。850+ 指使用者的聽讀總分目標，本站主要訓練閱讀。

TOEIC® 為 ETS 的註冊商標。本工具為獨立自學教材，未經 ETS 認可或推薦。
