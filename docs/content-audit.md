# 教材內容稽核與修訂

對象：目前總分約 600–750、目標 850+ 的學習者。原始檔 `多益閱讀文法自學講義.html` 保留不變；修訂只套用於抽取後的資料。題目是學習練習，不宣稱官方試題或保證提分。

## 保留範圍與資料契約

- 17 個原始 sections：intro、ch1–ch15、appendix；課程數為 15，導讀與附錄不計入課程數。
- 97 題：第 1–13 章各 6 題、Part 6 一篇 4 題、綜合測驗 15 題。原首頁「100+ 題」不適用於這份題庫。
- 題目 ID 對應原瀏覽器產生的 `data-qid`，從 q_0 到 q_96，維持原順序。選項未打散，解析中的答案字母維持一致。
- Part 6 的 q_78–q_81 共用完整 CRM 備忘錄，setId 為 ch14；文章同時留在原章節的完整講義中。
- 原有講義、表格、公式、延伸例句、回顧清單及附錄均保留；互動題目移為獨立資料，避免把答案或選項在題幹中重複呈現。
- 輸出移除 script／style、iframe／object／embed 與行內事件處理器；不沿用原頁的作答程式。
- 每個章節新增一句摘要與 850+ 讀法提醒；重要概念連接到長句理解、上下文、指涉及同義改寫。

## 對 850+ 目標的使用限制與建議

原題庫主要測文法，沒有完整 Part 7 題組，Part 6 也只有一篇。這些題目適合補觀念與診斷，不能單獨代表完整閱讀能力；需搭配補充模組的單篇、多篇、詞彙搭配及段落連貫練習。閱讀總題數的過半數來自 Part 7，不能把全部練習時間都留在文法。

原答案位置分布是 A 20、B 42、C 32、D 3，B+C 占 76.3%。目前保留順序以避免解析字母漂移；若將來打散選項，應以選項 ID 對應答案並同步調整解析。限時測驗應在交卷後才揭露答案，統計保留首次答錯，避免重做後的數字掩蓋初次掌握程度。

建議學習流程：短診斷 → 每日混合練習 → 錯題回到微課 → 間隔重做 → 完整限時閱讀。檢討錯題時記錄文法觀念、字彙搭配、指涉、推論、定位或時間壓力；分開查看正確率與耗時。850+ 是聽讀總分目標，本題庫不能換算正式 TOEIC 分數。

## 來源核對

正式紙筆 TOEIC 閱讀為 100 題、75 分鐘，Part 5／6／7 分別為 30／16／54 題；其中 Part 7 單篇 29 題、多篇 25 題。正式分數使用依試卷等化的換算程序，自編題正確率不直接對應正式成績。來源：[ETS 考生手冊](https://www.ets.org/pdfs/toeic/toeic-listening-reading-test-examinee-handbook.pdf)。

介系詞與連接詞依用法判斷，before、since、until 可兼具不同功能。來源：[Cambridge Grammar：Prepositions](https://dictionary.cambridge.org/us/grammar/british-grammar/prepositions_2)。

## 重建與驗證

```powershell
python -X utf8 scripts/extract-handbook.py --self-test
python -X utf8 scripts/extract-handbook.py
node --input-type=module -e "import { chapters, questions } from './data/handbook.mjs'; console.log(chapters.length, questions.length);"
```

抽取器包含 7 項驗證，涵蓋原題 ID 與答案、完整題組文章、四個選項、重複互動標記移除、危險行內程式移除、特定內容修訂與 schema。主流程也會核對解析答案字母、章節與題目對應，以及 q_0–q_96 唯一性。

驗證結果：17 sections、15 課、97 題；93 題單句練習（含綜合驗收）、4 題 Part 6、一個完整 Part 6 題組。ES module 可由 Node 直接載入。
