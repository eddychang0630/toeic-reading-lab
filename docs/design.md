# ReadLab 多益閱讀 App 設計

目標：將原有多益文法講義改為以手機為主、平板與電腦可用的閱讀學習 PWA，發布到使用者 GitHub Pages。使用者程度約 600–750，目標 850+。

採用免建置 HTML/CSS/ES modules，沒有帳號、外部付費服務或 API 金鑰。學習資料只存在目前瀏覽器，提供 JSON 匯出與匯入以跨裝置移轉。首次連線後快取靜態資源供離線使用。

主要流程：首頁每日練習 → 章節重點與完整講義 → 單題作答與中文解析 → 錯題間隔複習。補充 Part 7 單篇及多篇閱讀、Part 6 完整題組、商務詞彙卡片與 28 天學習路線。限時練習交卷後才顯示答案，練習模式答題後顯示解析。閱讀題組保持文章與題目一致。

保留原教材，不直接覆寫。修正錯誤文法口訣與譯文；新增題明確為原創練習，不宣稱官方試題或保證分數。測驗格式連結 ETS 來源；自訂時間配置清楚標示練習建議。

視覺：米白背景、深藍字色、深青綠強調色，手機底部導覽、電腦側欄。英文閱讀字級可調；按鈕至少 44 px、支援鍵盤與螢幕閱讀器、保留縮放、避免全頁橫向溢出。桌面文章與題目可並排，手機直向閱讀。

驗收：題目與答案 schema 完整且 ID 唯一；錯題重做、複習排程、計時交卷、作答持續保存、匯出匯入與離線可用；手機 390 px、平板 768 px、桌面 1440 px 無全頁水平捲動；GitHub Pages HTTP 成功且部署內容與本機一致。
